# Restaurant Management System

This is a simple Python project for managing customer orders in a restaurant. It uses Object-Oriented Programming (OOP) concepts to store customer details, manage food orders, update order status, and generate bills.

## What This Project Does

* Stores customer details
* Displays restaurant and customer information
* Adds food items to an order
* Calculates the total bill
* Checks and updates order status
* Updates customer mobile numbers
* Generates the final bill

## How It Works

1. The program creates a customer object.
2. It displays customer and order details.
3. Food items can be added to the order.
4. The total bill is updated automatically.
5. The order status can be checked and updated.
6. The final bill is displayed.

## How To Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

   `python restaurant.py`
